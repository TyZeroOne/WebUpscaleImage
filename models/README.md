# `models/`

Пусто до **этапа 5**.

Сюда лягут веса лёгкой SR-модели (класса FSRCNN/ESPCN) в формате ONNX,
либо скрипт их загрузки на этапе сборки.

Модель кладётся в пакет расширения, а не подтягивается в рантайме: требование
проекта — картинки пользователя никогда не покидают машину, и самый надёжный
способ это гарантировать — не иметь сетевых запросов вообще. Разовая загрузка
весов на этапе сборки этому не противоречит, загрузка при первом использовании —
уже спорно, потому что создаёт сетевую активность в момент работы с картинкой.

Ограничение, которое надо держать в голове при выборе модели: пакет
Chrome Web Store не должен раздуваться, а WASM-фоллбек должен успевать
считать за разумное время на слабой машине. Это отсекает тяжёлые модели
(Real-ESRGAN и подобные) в пользу моделей на сотни килобайт.
