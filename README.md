# ImageEnhancer

Расширение для Chrome (Manifest V3), которое улучшает изображения прямо на веб-странице:
увеличивает их, повышает качество и приводит к нужному разрешению. Все вычисления идут
**локально, на вашем устройстве**: картинки никуда не отправляются.

*English: a Chrome MV3 extension that upscales and enhances images right on the page,
fully locally (TensorFlow.js on WebGPU with a WASM fallback). Documentation is in Russian.*

## Возможности

Наведите курсор на картинку или откройте контекстное меню, и появятся три действия:

| Действие | Что делает |
|---|---|
| **Увеличить** | Увеличивает картинку в нужное число раз нейросетью или фильтром |
| **Качество** | Улучшает картинку, не меняя её размер (суперсэмплинг: увеличение моделью, затем уменьшение до исходного размера) |
| **Размер** | Приводит картинку к заданному разрешению, в большую или меньшую сторону |

Кроме этого:

- **Нейросети на выбор:** ESRGAN, Real-CUGAN и Real-ESRGAN. По умолчанию используется Real-ESRGAN: она
  обучена на смоделированных настоящих искажениях (сжатие, шум, смаз).
- **Три уровня качества и автоматический выбор** с понижением по возможностям устройства.
- **Графическое ускорение:** WebGPU, а если его нет, то WASM SIMD. Без обоих работает классический
  фильтр Ланцоша на Canvas.
- **Сохранение прозрачности** у PNG, логотипов и иконок.
- **Вычисления вне страницы:** тяжёлая работа идёт в Web Worker, поэтому сайт не зависает.
- **Понятные причины отказа**, если сайт закрыл доступ к картинке (CORS).
- **Интерфейс на русском и английском.**

## Приватность

Расширение не собирает данные и не обращается ни к каким серверам, кроме сайта, с которого
взята сама картинка. Подробности и объяснение каждого разрешения: [docs/PRIVACY.md](docs/PRIVACY.md).

## Установка из исходников

Нужны Node.js и npm, а также Chrome 116 или новее.

```bash
npm install
npm run build
```

Затем:

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку `dist/`.

Для разработки с пересборкой при изменении файлов запускайте `npm run dev`.

## Команды

```bash
npm install        # установить зависимости
npm run dev        # сборка с отслеживанием изменений
npm run build      # продакшн-сборка в dist/
npm run package    # сборка, проверки и zip для Chrome Web Store
npm run typecheck  # проверка типов (сборка типы не проверяет)
npm run icons      # перегенерация иконок
npm run clean      # удалить dist/
```

## Технологии

- TypeScript 7 (компилятор используется только для проверки типов), сборка на Vite 8
- TensorFlow.js 4.22 с бэкендами WebGPU и WASM
- Canvas 2D и собственная реализация фильтра Ланцоша
- Web Workers, `chrome.storage.sync`, `chrome.i18n`
- Всё необходимое (код, WASM и веса моделей) поставляется внутри пакета расширения, внешних запросов нет

## Статус

Версия 1.0.0. Сборка и проверки выполнялись в изолированном стенде с заглушкой `chrome` API.

не реализована: в коде есть только заглушка архитектуры.
